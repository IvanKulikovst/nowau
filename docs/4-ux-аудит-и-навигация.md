# UX-аудит и новая навигация

Дата: 27.10.2026. Основной пользователь — учебно-методический отдел (решение пользователя). Ролей и входа по паролю в приложении нет: это один HTML-файл, данные хранятся в браузере (localStorage). Поэтому ограничения доступа не менялись.

## 1. Краткое резюме

До переработки было 41 маршрут и 28 пунктов в одном плоском меню. Карточка курсанта была разбита на 4 отдельных экрана. Кнопки «Назад» были только на части экранов, и подписаны по-разному. Названия разделов повторяли термины методики («Объекты оценки», «Наборы Кзнк», «Самопроверка»). Удаление в одном месте было окончательным, в другом — через корзину.

Теперь:
- **5 разделов**: Главная · Оценки · Курсанты и выпускники · Анализ · Методика. Отдельно — сервис: данные и резервные копии, корзина, справка, «Как пользоваться».
- Внутри раздела экраны собраны в группы: «Ввести / Просмотреть», «Результаты / Прогноз g».
- Единая кнопка **«‹ Назад»** с названием экрана, на который она ведёт.
- Карточка курсанта стала **одним экраном с вкладками**.
- Все удаления идут через корзину. Сразу после удаления можно нажать **«Отменить»**.
- Единые пустые состояния, экран ошибки, индикатор длительных операций.
- Первые шаги для нового пользователя на главной и поиск любой функции по слову.

Расчёты, данные, адреса (#/…) и формат хранения не менялись.

## 3. Новая информационная архитектура

```
Главная (#/)                     — что требует внимания + быстрые действия
Оценки
  Ввести:      Новая оценка (#/new) · Ввод по группе (#/batch) · Импорт из файла (#/import)
  Просмотреть: Все оценки (#/history) · Журнал контроля (#/journal) · Отчёты о практике (#/preports) · Бланки для печати (#/blanks)
  Детальные:   Результат оценки (#/a/:id) → Отчёт (#/a/:id/report); Ввод данных (#/a/:id/edit/1…4); Ведомость (#/journal/sheet); Отчёт о практике (#/preport/:id)
Курсанты и выпускники (#/objects)
  Карточка: Оценки (#/object/:id) · Профиль (/profile) · Карта этапов (/map) · Отчёт (/report) · Практика и служба (#/followup/:id, если есть пара) · Сведения (/edit)
  Сравнение двух оценок (#/compare/:a/:b)
Анализ
  Результаты: Сводная по группе · Группы риска · Отзывы из войск · Практика и служба · Сравнение групп · Статистика
  Прогноз g:  Прогноз по группе · Чувствительность · Оптимизация плана · Дисциплины и ВПК
Методика
  Справочник (#/method/…) · Коэффициенты Кзнк (#/coef, #/coef/:id, #/expert/:id) · Паспорта компетенций · Учебные планы (#/curricula, #/curriculum/:id) · Модели Y (#/ymodels, #/ymodel/:id) · Проверка расчётов (#/tests)
Сервис: Данные и резервные копии (#/data) · Корзина (#/trash) · Справка (F1) · Как пользоваться
```

Важные функции находятся не глубже двух уровней: раздел → экран. Детальные экраны — третий уровень, у всех есть «Назад».

Структура описана одной таблицей `NAV` в модуле `45-nav.js`. Новый экран добавляется одной строкой: в меню, вкладки, поиск и «Назад» он попадает автоматически.

## 4. Схема навигации

- **Компьютер.** Слева меню из 5 разделов. У текущего раздела раскрыты его экраны, сгруппированные по смыслу. Ниже — сервис. Вверху меню — поиск «Найти раздел или функцию»: ищет по названиям и пояснениям; Enter открывает первый результат, Esc очищает.
- **Телефон.** Внизу плавающая панель из 5 кнопок: Главная · Оценки · Курсанты · Анализ · Ещё. «Ещё» открывает полное меню листом снизу; закрыть — касанием вне листа или Esc. Вкладки текущего раздела показаны над содержимым и прокручиваются вбок.
- **«‹ Назад»** есть на каждом детальном экране. Ведёт туда, откуда пользователь пришёл (по стеку переходов). Если экран открыт по прямой ссылке — к родительскому экрану. Подпись всегда называет цель: «‹ Иванов И.И.», «‹ Все оценки». Шаги мастера ввода считаются одним экраном, поэтому «Назад» не листает шаги.
- **Где ты находишься:** выделенный раздел и подпункт в меню, активная вкладка, справа от «Назад» — название раздела, в верхней строке на телефоне и в заголовке окна — название экрана.

```
Главная ──► Новая оценка ──► Ввод данных (шаги 1–4) ──► Результат ──► Отчёт для печати
   │                                  ▲ «‹ Все оценки» / «‹ откуда пришли»
   ├──► Курсанты ──► Карточка [Оценки | Профиль | Карта этапов | Отчёт | Сведения]
   │                    └──► Результат оценки («‹ Иванов И.И.»)
   ├──► Группы риска ──► Карточка курсанта
   └──► Незавершённые оценки ──► Ввод данных
```

## 5. Основные пользовательские сценарии

**С1. Ввести анкету практики курсанта**
- *Цель:* получить уровень сформированности ВПК по анкете.
- *Начало:* Главная → «Новая оценка», или карточка курсанта → «＋ Новая оценка» (курсант уже выбран).
- *Шаги:* выбрать курсанта и вид оценки → параметры (дата, курс, оценщик) → оценки 1–5 кнопками → проверка → «Утвердить».
- *Результат:* экран результата с уровнем; «‹ Назад» ведёт к курсанту.
- *Ошибки и другие пути:* не все компетенции заполнены — незаполненные строки отмечены, «Утвердить» объясняет, чего не хватает. Если ввод прерван — черновик сохраняется автоматически и появляется на Главной в блоке «Незавершённые оценки» с кнопкой «Продолжить». Если курсанта ещё нет — его можно добавить прямо на первом шаге.

**С2. Ввести оценки всей группы**
- *Начало:* Оценки → «Ввод по группе» (или «Импорт из файла», если оценки уже в Excel).
- *Шаги:* выбрать группу и вид → заполнить таблицу (можно вставить из Excel) → «Создать записи» → подтверждение с числом записей.
- *Результат:* утверждённые оценки по каждому курсанту, сообщение о количестве.
- *Ошибки:* недопустимые значения подсвечиваются до сохранения; при импорте каждая строка проверяется, курсанты сопоставляются по ФИО.

**С3. Найти отстающих и разобраться**
- *Начало:* Главная → предупреждение «Группы риска» или плитка «Группы риска».
- *Шаги:* список с признаками → нажать на ФИО → карточка → вкладка «Профиль» (компетенции ниже среднего по группе).
- *Результат:* понятно, какие компетенции проседают и с какой оценки это видно.
- *Другие пути:* Анализ → «Сводная по группе» (место в группе) или «Практика и служба» (практика против отзыва).

**С4. Подготовить отчёт для печати**
- *Начало:* карточка курсанта → вкладка «Отчёт», или результат оценки → «Отчёт для печати», или Анализ → «Сводная по группе» → «Печать / PDF».
- *Результат:* печать или PDF через системный диалог. Навигация и кнопки на печать не выводятся.

**С5. Исправить ошибочно утверждённую оценку**
- *Начало:* результат оценки → «Исправить оценки».
- *Шаги:* подтверждение («прежний результат сохранится в истории редакций») → исправить → «Утвердить».
- *Результат:* новая редакция; в разделе «Предыдущие редакции» виден прежний результат.
- *Отмена:* «Отменить редактирование» возвращает последнюю утверждённую редакцию.

**С6. Удалить по ошибке и вернуть**
- *Начало:* карточка → «Сведения» → «Удалить курсанта».
- *Шаги:* подтверждение (что и сколько переместится в корзину) → сообщение «… удалён» с кнопкой «Отменить».
- *Результат:* «Отменить» возвращает курсанта вместе с оценками и записями журнала. Позже — Сервис → «Корзина» (хранится 30 дней).

**С7. Первый запуск**
- *Начало:* пустая Главная → «С чего начать».
- *Шаги:* добавить курсантов → ввести оценки → утвердить и посмотреть анализ → сохранить резервную копию. Выполненные шаги отмечаются галочкой. Альтернатива — «Откройте демонстрационные данные»: они загружаются в отдельный учебный режим.
- *Результат:* после всех шагов блок исчезает сам; его можно скрыть раньше и вернуть кнопкой в сообщении.

**С8. Найти функцию, не зная, где она**
- *Начало:* поле «Найти раздел или функцию» в меню.
- *Шаги:* ввести слово («бланк», «корреляц», «дубл») → Enter.
- *Результат:* нужный экран открыт. Если ничего не найдено, предлагается справка.

## 7. Расположение кнопок (единые правила)

- Главное действие экрана — синяя кнопка справа от заголовка: «＋ Новая оценка» в «Все оценки» и в карточке курсанта, «Добавить» в строке добавления.
- Второстепенные действия — серые кнопки в ряд под заголовком.
- Опасное действие — красная кнопка, отделена от остальных (справа в ряду или в отдельном блоке «Удаление»). Всегда с подтверждением, в котором сказано, что произойдёт и как это вернуть.
- Печать — «Печать / PDF» или «Отчёт для печати»; служебные элементы на печать не выводятся.
- Фильтры — над таблицей, с кнопкой «Сбросить фильтры». Число найденных записей видно всегда.

## 8. Состояния экранов

| Состояние | Как выглядит |
|---|---|
| Пусто (данных ещё нет) | значок, что здесь появится, кнопка следующего шага |
| Пусто (не подошло под фильтр) | «Ничего не найдено», «Сбросить фильтры» |
| Запись не найдена | «… — не найдено», «Назад», «Корзина» |
| Неизвестный адрес | «Страница не найдена», «На главную» |
| Ошибка построения экрана | «Не удалось открыть раздел», данные целы, «Назад», «На главную», подробности |
| Длительная операция | индикатор с текстом (демо-данные, чтение файла; расчёт оптимизации — «Выполняется расчёт…») |
| Успех | сообщение сверху; где уместно — с действием («Открыть карточку», «Вернуть») |
| Удаление | подтверждение, затем сообщение с «Отменить»; корзина на 30 дней |
| Отмена ввода | черновик сохраняется автоматически; «Отменить редактирование» у новой редакции |
| Хранилище недоступно | красное предупреждение на Главной и в меню |

## 9. Приоритетный план

**Критично (сделано):** пять разделов вместо 28 пунктов; единая «Назад»; карточка курсанта с вкладками; удаление только через корзину с «Отменить»; экран ошибки и «не найдено»; понятные названия кнопок результата.

**Важно (сделано):** быстрое добавление курсанта и предупреждение о повторе; дубли в списке курсантов; фильтр по группе и сортировка; первые шаги и «Как пользоваться»; «Незавершённые оценки» на Главной; поиск функций по словам; индикатор длительных операций; название экрана в верхней строке; панель разделов на телефоне.

**Желательно (предложено, не сделано):**
1. Отображаемые столбцы и сохранённые фильтры в «Все оценки» и «Журнал контроля».
2. Массовые действия в списке курсантов (перевести в другую группу, удалить выбранных).
3. Интерактивный тур с подсветкой элементов при первом запуске (сейчас — текстовое окно).
4. Единый экран «Отчёты» (курсант, группа, практика) вместо печати из разных мест.
5. Режим «только ввод» для командиров — по одной анкете на экран, если приложение будут давать и им.

## 11. Риски и нерешённые вопросы

- **Сохранённые закладки на старые экраны** работают: все адреса прежние. Новый адрес один: `#/object/:id/edit` («Сведения»).
- **«Назад» по стеку** хранит историю только в пределах открытой вкладки. После перезагрузки страницы «Назад» ведёт к родительскому экрану.
- **Вкладки разделов на компьютере скрыты**, потому что те же пункты есть в меню слева. Если окно узкое (до 760 px), вкладки показываются над содержимым.
- **«Практика и служба»** есть и в «Анализе», и вкладкой в карточке курсанта. Это один и тот же экран, открытый с двух сторон; «Назад» ведёт туда, откуда пришли.
- **Длинные операции идут в основном потоке браузера.** Индикатор показывается, но экран на это время не реагирует на нажатия. Для 60 человек загрузка занимает меньше секунды.
- **Ролей нет.** Если появятся разные пользователи (УМО и командиры), понадобятся режим «только ввод» и раздельные хранилища или экспорт и импорт между ними.


## 12. Дополнение (27.10.2026)

- Добавлен шестой раздел **«Отчёты»**: все печатные формы в одном месте — по курсанту, по группе, документы практики, бланки и выгрузки. «Отчёты о практике» и «Бланки для печати» перенесены сюда из «Оценок».
- В списке курсантов — **действия над несколькими**: «Перевести в группу…», «Удалить выбранных» (обе с отменой).
- В **диагностическом профиле** — краткое название и формулировка каждой компетенции и автоматическая характеристика: сильные стороны, зоны развития, динамика.
- Оформление переведено в стиль **«жидкое стекло»**: полупрозрачные материалы с размытием, блик по кромке, свечение под курсором на кнопках и вкладках, пружинные анимации нажатия и появления экранов; при настройке «уменьшить движение» анимации отключаются.
