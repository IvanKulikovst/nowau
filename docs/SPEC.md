# КРПД — спецификация интерфейса (версия 2.0)

Основание: приказ Росгвардии от 14.07.2025 № 270. Приложение — один HTML-файл, работает без интернета, данные хранятся в браузере.

## 1. Архитектура интерфейса

```
┌──────────────────────────────────────────────────────────────────────────┐
│ КРПД  Файл  Правка  Вид  Расчёт  Документы  Справка          ← строка меню│
├───────────────┬──────────────────────────────────────────────────────────┤
│ [Новый расчёт]│  Обзор потребления     [быстрые действия]                 │
│ Главная    ▸  │  ┌ объём ┐ ┌ масса ┐ ┌ кол-во ┐   ← KPI                   │
│ Расчёт     ▾  │  ┌ структура ┐ ┌ крупнейшие ┐                            │
│  · Новый      │  ┌ динамика м³/сут ───────────┐ ┌ последние документы ┐   │
│  · Загрузить  │  Расчёты (карточки), Данные и печать                     │
│  · История    ├──────────────────────────────────────────────────────────┤
│  · Шаблоны    │ статус: расчётов · объём · масса │ приказ № 270 │ сеть │ % │
│ Документы  ▸  └──────────────────────────────────────────────────────────┘
│ Печать     ▸
│ Настройки  ▸        Окна поверх: Печать (предпросмотр) · Справочные данные
│ [Тема ☀ ◐ ☾]                     · История / Шаблоны / Настройки
└───────────────┘
```

Компоненты и данные:
- **Ядро** (`index.html`): расчёт норм, хранилище (IndexedDB + localStorage), форма расчёта, список, графики. Экспортирует `window.KRPD` (расчёт, данные таблиц, модель печати).
- **Справочник** (`src/reference.js`): строит содержимое из тех же таблиц и констант, что использует расчёт; примеры считает движок программы — расхождений быть не может.
- **Расширения** (`src/extras.js`): меню разделов, строка меню, строка состояния, окно печати, справочник, настройки.
- Поток данных: `форма расчёта → хранилище → render() → KPI/графики/карточки → модель печати → предпросмотр/печать/экспорт`.

## 2. Разделы (у каждого своё меню)

Клик по разделу раскрывает **только его** подменю в боковой панели (на телефоне — всплывающая панель над нижней вкладкой). Активный раздел подсвечивается цветом, левой полосой и стрелкой. Горячие клавиши: **Alt+1…Alt+5** (и Ctrl+1…5, если браузер их отдаёт странице).

| Раздел | Пункты | Действие |
|---|---|---|
| Главная | Обзор · Быстрые действия · Последние расчёты · Последние документы | прокрутка к блоку |
| Расчёт | Новый расчёт · Загрузить расчёт · История расчётов · Шаблоны расчётов | форма; импорт файла; архив с поиском; 13 готовых форм по типам объектов |
| Документы | Приказы · Дополнения · Шаблоны документов | приказ № 270 (→ справочник); дополнений в материалах нет; формы приложений № 1–4 |
| Печать | Предпросмотр · Настройки печати · История печати | окно печати; журнал печати и экспорта |
| Настройки | Пользователь · Организация · Параметры расчёта | профиль (подставляется в подписи), часть и дислокация, КПД/Qт/ρ по умолчанию и константы приказа |

Сценарий: Главная → «Новый расчёт» → ввод параметров (результат виден сразу) → «Печать» → предпросмотр → PDF/Word/Excel.

## 3. Окно печати

```
┌ Предпросмотр и печать — приказ № 270            ⛶  ▢  ✕ ┐  ← перетаскивается
│ 50 75 100 150 200 ─●─ 77% │ По ширине/По высоте/Вместить │ ⏮ ◀ [1] ▶ ⏭ Страница 1 из N │
├────────┬─────────────────────────────────────┬─────────────────────┤
│миниатюры│   реалистичный лист с тенью,        │ Документ: форма, год,│
│ страниц │   полями, колонтитулом и номером    │  месяц, часть, подписи│
│  ▢ 1   │   страницы; режим N страниц на листе │ Печать: принтер,     │
│  ▢ 2   │                                     │  копии, ориентация,  │
│        │                                     │  бумага, поля,       │
│        │                                     │  дуплекс, цвет/ч-б,  │
│        │                                     │  колонтитулы, №стр.  │
│        │                                     │ Шаблоны печати       │
├────────┴─────────────────────────────────────┴─────────────────────┤
│ PDF · Word · Excel · e-mail │ статус          │ Закрыть   [Печать] │
└────────────────────────────────────────────────────────────────────┘
```

Минимум 1200×800 (на меньших экранах — на весь экран), изменение размера за угол, перемещение за заголовок, ▢ — развернуть, F11 — полный экран.

| Элемент | Поведение |
|---|---|
| Масштаб | кнопки 50/75/100/150/200 %, ползунок 25–300 %, «По ширине/По высоте/Вместить» (пересчитывается при изменении размера окна), Ctrl +/− |
| Страницы | миниатюры, первая/предыдущая/следующая/последняя, ввод номера, «Страница X из Y», PgUp/PgDn; текущая страница определяется по прокрутке |
| Принтер | браузер не раскрывает список принтеров: конкретный принтер выбирается в системном окне; варианты «системное окно» и «сохранить как PDF» |
| Копии | счётчик 1–99: форма реально повторяется в печати нужное число раз |
| Ориентация / бумага | книжная/альбомная; A3, A4, A5, Letter, Legal — применяется и к предпросмотру, и к `@page` печати |
| Поля | четыре значения в мм, пунктир и размеры листа отражаются в предпросмотре |
| Двусторонняя | каждая копия начинается с нового листа (`break-before: right`); сам режим дуплекса задаёт принтер |
| Цвет / ч-б | ч-б включает `grayscale` при печати |
| Колонтитул, номера страниц | в предпросмотре и в печати (`@page` margin boxes) |
| Несколько страниц на листе | 1/2/4 — только в предпросмотре |
| Экспорт | PDF — через «Сохранить как PDF» в системном окне; Word — файл `.doc`; Excel — файл `.xls` с таблицами формы; e-mail — письмо с итогами (вложить файл нужно вручную) |
| Шаблоны печати | сохранение и применение наборов параметров |
| Разбивка на страницы | приблизительная (строки таблиц могут переноситься иначе) |

## 4. Строка меню

| Меню | Пункты (горячие клавиши) | Состояния |
|---|---|---|
| Файл | Новый (Ctrl+N) · Открыть (Ctrl+O) · Сохранить (Ctrl+S) · Сохранить как… (Ctrl+Shift+S) · Импорт · Экспорт · Печать (Ctrl+P) · Предпросмотр (Ctrl+Shift+P) · Выход (Alt+F4) | «Сохранить/Экспорт» неактивны при пустом списке; «Выход» подсказывает закрыть вкладку (браузер не даёт закрыть её программой) |
| Правка | Отменить (Ctrl+Z) · Повторить (Ctrl+Y) · Вырезать/Копировать/Вставить · Найти (Ctrl+F) · Заменить (Ctrl+H) | «Отменить» активно при наличии шага; «Повторить» не поддерживается (неактивно); буфер — когда есть поле/выделение; «Заменить» работает в активном поле |
| Вид | Панель инструментов · Строка состояния · Боковая панель (галочки) · Масштаб ▸ 80–150 % · Полный экран (F11) | настройки запоминаются |
| Расчёт | Новый · Загрузить · Пересчитать все (F5) · Проверить данные · История · Шаблоны | «Проверить данные» показывает расчёты с ошибками |
| Документы | Приказы · Дополнения · Шаблоны документов · Архив документов | — |
| Справка | **Справочные данные (F1)** · Руководство · О программе · Проверить обновления | «Обновления» сообщает, что программа автономна |

Клавиатура: ←/→ — соседнее меню, ↑/↓ — пункты, Enter — выбрать, Esc — закрыть.

## 5. Справочные данные (F1)

Окно: оглавление слева (разделы, закладки, история), поиск с подсветкой и счётчиком (Enter/Shift+Enter, Ctrl+F), закладки (Ctrl+B), копирование раздела, печать раздела/всего, экспорт в PDF, экспорт таблиц в Excel. Каждое положение привязано к пункту приказа (метки-ссылки).

1. **Основания расчёта** — полный текст приказа и Порядка (п. 1–17), юридическое обоснование (ч. 1 ст. 31 № 226-ФЗ), область применения (п. 1, 2, 4), срок действия (в приказе не установлен; сроки процедур 15 марта / 5 апреля / 1 мая), дополнения (в материалах нет).
2. **Формулы** — Ф1 норма N, Ф2 поправка C1, Ф3 K, Ф4 масса M, Ф5 объём V, Ф6 эшелонированный запас; для каждой: запись, переменные, шаги, пример, ссылка на пункт. Формулы M, V приведены как методика программы (в тексте приказа не заданы) — это указано прямо.
3. **Таблицы** — Нормы № 1 (9 таблиц палаток), № 2, № 3, № 4 в исходном виде со страницей скана, единицей измерения, примечанием, датой утверждения; экспорт в Excel.
4. **Коэффициенты и константы** — значение по умолчанию, диапазон, источник (пункт приказа или «значение программы»).
5. **Примеры** — 8 примеров, считаются самой программой; типичные ошибки.
6. **Пояснения** — глоссарий, FAQ, связанные документы (СП 131.13330.2020, ГОСТ 3243-88).

## 6. Техническая реализация

- Один файл HTML/CSS/JS без зависимостей; исходники расширений — `src/`, сборка `python3 build-standalone.py` (подставляет `src/` в `index.html` и собирает `krpd-standalone.html` со встроенными видео и картинками).
- Состояние: IndexedDB + localStorage; настройки/журнал печати/закладки — localStorage (`krpd-firewood.*`).
- Печать: `#printRoot` + динамический `@page` (размер, поля, колонтитулы), `window.print()`.
- Экспорт Word/Excel: HTML в Blob с типами `application/msword` / `application/vnd.ms-excel`.
- Проверка: встроенная самопроверка (`#selftest`), 30 тестов расчёта, валидации, печати.

Ключевой код — динамический `@page`:
```js
css = '@page{size:' + paper + ' ' + orient + ';margin:' + mt + 'mm ' + mr + 'mm ' + mb + 'mm ' + ml + 'mm;' +
      '@bottom-center{content:"Страница " counter(page) " из " counter(pages)}}';
```

## 7. UX-рекомендации

- Умолчания: КПД 0,7 (п. 13), +18 °C внутри, топка 12 ч; параметры в «Настройках» подставляются в новые расчёты.
- Прогрессивное раскрытие: подменю видно только у активного раздела; редкие параметры печати — в правой панели окна.
- Обратная связь: подсветка активного раздела, плавное раскрытие подменю, тосты, анимации графиков, предпросмотр результата до сохранения.
- Автономная работа: индикатор «Онлайн / Автономно» в строке состояния; нижняя панель вкладок на телефоне.
- Идеи: сравнение двух сценариев расчёта (разные КПД/породы); режим «сводка к 15 марта» с автоматическим заполнением приложений № 1–2; подсветка в справочнике пункта приказа, из которого взята норма выбранного расчёта.

## Известные ограничения (браузер)

Нет списка принтеров, нет автоматического выбора дуплекса, отправка e-mail без вложения, невозможность закрыть вкладку программой, часть горячих клавиш (Ctrl+N, Ctrl+W, Ctrl+1…9) зарезервирована браузером — для разделов продублирована Alt+1…5.
