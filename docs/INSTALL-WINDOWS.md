# Установка на Windows

## Вариант 1 (рекомендуется): приложение-установщик

Файл `Reglament-TS-Setup-<версия>.exe` — самостоятельное приложение: собственное окно, данные в обычных файлах (`Документы\Регламент-ТС`), без браузера. Права администратора и интернет не нужны, нужна Windows 10 или 11 (64 бита).

1. Запустите `Reglament-TS-Setup-<версия>.exe` и пройдите установку. Появятся ярлыки на рабочем столе и в меню «Пуск».
2. Если Windows покажет «Windows защитила ваш компьютер»: «Подробнее» → «Выполнить в любом случае» (приложение не подписано сертификатом).
3. Данные из прежней версии в браузере переносятся один раз: в браузере «Сохранность данных → Создать резервную копию», в приложении «Восстановить из копии».
4. Обновление: запустите новый установщик поверх старого, данные сохранятся.
5. Удаление — «Приложения и возможности» Windows. Папка с данными остаётся.

**Переносная версия** (`Reglament-TS-Portable-<версия>.zip`): распакуйте на флешку и запустите `Reglament-TS.exe`; данные лежат в папке «Данные Регламент-ТС» рядом и переносятся вместе с ней.

Подробности устройства и сборки — в `app/README.md`.

## Вариант 2: ярлык на базе Edge/Chrome (без установщика приложения)

Интернет и права администратора не нужны. Нужен Microsoft Edge (есть в Windows 10 и 11) или Google Chrome.

## Установка

1. Положите в одну папку `index.html` и содержимое папки `windows` (`install.cmd`, `install.ps1`, `uninstall.cmd`, `uninstall.ps1`, `rollback.cmd`).
2. Запустите `install.cmd`.
3. На рабочем столе и в меню «Пуск» появится ярлык **«Регламент-ТС»**. Программа открывается в отдельном окне, без адресной строки и вкладок.

Куда устанавливается:

| Что | Где |
|---|---|
| Программа | `%LOCALAPPDATA%\Reglament-TST\app\index.html` |
| Предыдущая версия (для отката) | `%LOCALAPPDATA%\Reglament-TST\app\index.previous.html` |
| Данные (собственный профиль браузера) | `%LOCALAPPDATA%\Reglament-TST\profile` |

Собственный профиль означает: очистка истории в обычном браузере данные программы не затрагивает.

### Перенос данных, если программа уже использовалась в браузере

Данные в обычном браузере и в окне программы — **разные хранилища**. Перенесите их один раз:

1. В старом окне: «Сохранность данных» → «Создать резервную копию».
2. В окне «Регламент-ТС»: «Сохранность данных» → «Восстановить из копии» → выбрать сохранённый ZIP.

## Обновление программы

Положите новый `index.html` рядом с `install.cmd` и запустите его ещё раз. Данные сохраняются. При первом запуске новой версии структура данных обновится сама, а перед этим программа создаст точку восстановления.

Если новая версия не устроила, запустите `%LOCALAPPDATA%\Reglament-TST\rollback.cmd` — вернётся предыдущий файл программы. Данные при необходимости откатываются в разделе «Сохранность данных» → «Точки восстановления».

## Переносной режим (флешка)

`Reglament-TST-portable.cmd` рядом с `index.html` запускает программу в окне приложения. Данные при этом хранятся в папке `data` рядом с ним и переносятся вместе с флешкой.

## Удаление

`uninstall.cmd` удаляет программу и ярлыки. **Данные остаются** в `%LOCALAPPDATA%\Reglament-TST\profile`. Удалить и данные:

```
powershell -ExecutionPolicy Bypass -File uninstall.ps1 -RemoveData
```

## Без установки

`index.html` можно просто открыть двойным щелчком: всё работает так же, но данные хранятся в обычном профиле браузера.

## Отдельное Windows-приложение (следующий этап)

Текущая установка использует уже имеющийся в Windows браузер Edge. Это не требует скачивания и обновляется вместе с Windows. Упаковка в самостоятельное приложение (Electron или WebView2) с собственным установщиком возможна без изменения программы. Для её сборки один раз понадобится интернет на компьютере разработчика.
