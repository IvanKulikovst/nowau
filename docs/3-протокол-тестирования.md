## 3. Обнаруженные и исправленные ошибки

| № | Ошибка | Исправление |
|---|---|---|
| 1 | Скрытая радиокнопка оценки перехватывала клики по соседним элементам | позиционирование внутри своей ячейки, `pointer-events:none` |

| 3 | Уведомления накапливались стопкой | не более 3 одновременно |

| 5 | Два собственных теста были сформулированы неверно (подбор примера расхождения уровней; округление g₁ в шаговом примере) | тесты исправлены; вычислительный модуль не менялся |

## 4. Что не проверено

- Браузеры Firefox и Safari, а также реальные Microsoft Edge / Google Chrome под Windows не запускались (проверен Chromium под Linux; Edge и Chrome используют тот же движок).
- Сохранение данных между запусками проверено в Chromium при открытии `file://` в одном профиле. Поведение хранилища при `file://` в других браузерах и при корпоративных политиках не проверялось — поэтому в приложении предусмотрены и рекомендуются резервные копии.
- Печать в PDF проверена только по наличию печатной вёрстки (стили `@media print`), сам системный диалог печати не вызывался.
- Открытие CSV в Microsoft Excel не проверялось (формат: «;», десятичная запятая, UTF-8 с BOM).
