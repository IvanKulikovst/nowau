## 3. Шкалы и уровни

Применяется значение из таблицы источника.*

## 4. Спецификации формул

### F1. Показатель сформированности компетенции

`Псфк_i = Оценка_i × Кзнк_i`

| | |
|---|---|
| Переменные и допустимые значения | Оценка — индивидуальная оценка компетенции командиром (руководителем практики), целое 1…5; Кзнк — коэффициент значимости компетенции (> 0). |
| Условия применения | Отзыв на выпускника (ВПК, ПСК), анкета практики (ВПК). |
| Порядок вычислений | Вычисляется для каждой компетенции набора. |
| Округление | Без округления; в таблицах — 5 знаков (программа ЭВМ) или 3 знака (табл. 7 S4). |
| Пропущенные данные | При пропуске оценки показатель не вычисляется, запись не может быть утверждена. |
| Источник | S1 разд. II; S2 Прил. 3 |
| Контрольный пример | ВПК-1: 4 × 0,06355 = 0,2542 (S2 Прил. 3). |

### F2. Суммарный показатель сформированности ВПК (ПСК)

`Псфк_сум = (1/n)·Σ Псфк_i`

| | |
|---|---|
| Переменные и допустимые значения | n — число компетенций набора (16 ВПК, 5 ПСК, 13 ВПК практики). |
| Условия применения | Все оценки набора выставлены. |
| Порядок вычислений | После F1. |
| Округление | Для сравнения с границами уровней — до 3 знаков (границы заданы с 3 знаками). |
| Пропущенные данные | Не вычисляется при неполном наборе. |
| Источник | S1 разд. II («определяется как среднеарифметическая величина») |
| Контрольный пример | Курсант Сердюк М.А.: Σ = 3,26556; /13 = 0,251 (S2 Прил. 3). |

### F3. Итоговая оценка сформированности компетенций

`Псфк_итог = (Σ Псфк_ВПК + Σ Псфк_ПСК) / (n_ВПК + n_ПСК)`

| | |
|---|---|
| Переменные и допустимые значения | Суммы по F1 для ВПК и ПСК. |
| Условия применения | Оценены и ВПК, и ПСК. |
| Порядок вычислений | После F1. |
| Округление | Сравнение — до 3 знаков. |
| Пропущенные данные | Без ПСК не вычисляется. |
| Источник | S1 разд. II (таблица границ); формула не приведена — принята по решению пользователя, согласуется с границами 0,236 и 0,170 |
| Контрольный пример | Все оценки 5: (5,00005 + 1,60685)/21 = 0,3146 ≤ 0,315. |

`g_0 = (Σ x_l + Σ y_l) / (5·(L_1 + L_2))`

| | |
|---|---|
| Переменные и допустимые значения | x — оценки аттестата (L1 шт.), y — оценки вступительных экзаменов (L2 шт.), 5-балльная шкала. |
| Условия применения | Дисциплины без предшествующих. |
| Порядок вычислений | — |
| Округление | Без округления. |
| Пропущенные данные | Должна быть хотя бы одна оценка. |
| Источник | S5 ф. (22), с. 93 |

### F9. Уровень подготовленности по дисциплине

`g = 1 − (1 − g_0)·e^(−p·(m·T_1 + T_2)/(1 − c))  [ф. 24];  g = 1 − (1 − g_0)·e^(−p·(m·T_1/(1 − c_1) + T_2/(1 − c_2)))  [ф. 21]`

| | |
|---|---|
| Переменные и допустимые значения | T1 — объём дисциплины (ч), T2 — самостоятельная работа (ч), m — относительное методическое мастерство преподавателя (0 ≤ m < 1 по S5 с. 85), c, c1, c2 — способности обучающегося (0 ≤ c < 1), p — интенсивность (ч⁻¹). |
| Условия применения | По умолчанию — ф. (24), p = 10⁻⁴ (рабочая формула алгоритма и контрольного примера); ф. (21) — альтернативный режим. |
| Порядок вычислений | g0 по F7 или F8, затем F9. |
| Округление | Без округления (источник округлял промежуточные g до 3 знаков). |
| Пропущенные данные | Все параметры обязательны. |
| Источник | S5 ф. (21), (24), с. 89, 96; S6 |
| Контрольный пример | g1 = 1 − 0,287·e^(−0,0001·(0,8·100+80)/0,5) = 0,722. |

## 7. Ограничения методики в приложении

- Пороги Псфк применимы только к наборам Кзнк источника; для пользовательских наборов уровень определяется только по bср.
- Для 13 ВПК практики уровень по Псфк не определяется (пороги не установлены).
- Итоговая оценка комиссии за практику и вывод командира не вычисляются, а вводятся.
- Весовые коэффициенты этапов (S4 табл. 6) и компоненты ВПК в расчётах не используются.
- Для Y уровни не установлены; признаки, веса и эталон — ответственность пользователя.
- Оптимизация плана максимизирует сумму по семестру до лимита (уровень g растёт с объёмом часов), использует формулу (24) и не гарантирует глобальный оптимум.
- В оптимизации по группе способность обучающегося c усредняется по дисциплинам.
