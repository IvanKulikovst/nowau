## 3. Определение компетенции в материалах

- ВПК — «интегративное качество личности курсанта, обеспечивающее готовность и способность к успешной служебно-боевой деятельности» (S3 п. 2.2, III); структура — 5 компонентов: когнитивный, операционально-деятельностный, мотивационно-ценностный, личностно-волевой, рефлексивный.
- Профессиональная компетентность — «интегральная характеристика, определяющая способность выпускника … решать профессиональные проблемы и задачи …» (S1 разд. I); «интегральная оценка овладения профессиональными и общекультурными компетенциями и профессионально значимыми личностными качествами».
- Перечень ВПК-1…16 — по квалификационным требованиям (ВУС 370300, 360200), сгруппирован по видам деятельности (общие, командная, педагогическая, воспитательная, военно-техническая, административно-хозяйственная) (S1).

## 4. Устройство модели полифункционального контроля

Цель — диагностика, оценка и коррекция уровня сформированности ВПК. Контроль ведётся на всех этапах (абитуриент → 1–5 курсы → 1–2 год службы): **мониторинг** (контрольные работы, летучки, групповые упражнения, ТСЗ, КШВИ) и **диагностика** (ЕГЭ, отбор, зачёты, экзамены, отзывы за практику, ГИА, отзывы из войск). Математический блок даёт g₀, g_ot, g, Y; результативный блок — эмпирические, квалиметрические показатели и графики; выход — один из четырёх уровней; обратная связь — коррекция программы подготовки.

## 6. Как проводится оценивание

1. Командир (руководитель практики) выставляет оценки 1–5 по каждой компетенции формы/анкеты.
2. Учебно-методический отдел подставляет Кзнк и рассчитывает Псфк (программа ЭВМ).
3. Вычисляются суммарные показатели, средний балл, % сформированности; строится график «показатель / минимум / максимум».
4. Уровень определяется по таблицам; результаты сопоставляются с оценками руководителей; по группе — ранжирование.
5. Итоговую оценку за практику выставляет комиссия по 4-балльной системе с учётом расчёта (правило не формализовано).

## 7. Подтверждённые формулы

`Псфк = Оценка × Кзнк`; суммарный = среднее арифметическое; % = bср/5·100; мин./макс. = 2·Кзнк / 5·Кзнк; g₀ (22); g_ot (23); g (24), (21); λ = Σs/ΣΣs; W и χ² для связанных рангов. Спецификации — в `2-паспорт-методики.md`.
