# ПФК ВПК — расчёт уровня сформированности военно-профессиональных компетенций

Автономное HTML-приложение (один файл `index.html`), реализующее модель полифункционального контроля сформированности ВПК курсантов и выпускников ВООВО по предоставленным методическим рекомендациям и материалам диссертации.

Работает без интернета, сервера и установки: HTML, CSS и JavaScript находятся в одном файле, внешние библиотеки и шрифты не используются.

## Состав репозитория

## Краткая инструкция

**Запуск.** Скопируйте `index.html` в любую папку и откройте двойным щелчком (Microsoft Edge, Google Chrome, Яндекс Браузер или Firefox актуальной версии).

**Первый расчёт.**
1. «Объекты оценки» → введите Фамилию И.О. и учебную группу → «Добавить».
2. «Новая оценка» → выберите объект и вид оценки:
   - *Отзыв на выпускника* — 16 ВПК и 5 ПСК по форме отзыва за 1-й или 2-й год службы;
   - *Анкета: войсковая практика* — анкета руководителя практики 4 (5) курса;
   - *Начальный уровень g₀*, *Уровень подготовленности по дисциплинам*, *Уровень компетентности Y* — математический блок модели.
3. Пройдите шаги мастера: параметры → ввод оценок (кнопки 1–5; незаполненные строки отмечены слева жёлтой полосой) → проверка. На шаге «Проверка и расчёт» показывается предварительный результат; неполные данные утвердить нельзя.
4. «Утвердить расчёт» — результат фиксируется вместе со снимком параметров методики.

**Результаты.** Карточка расчёта содержит итоговые показатели и уровни, таблицу по компетенциям, график «показатель / минимум / максимум», раскрывающийся блок «Как получено» с промежуточными значениями. Кнопки: «Отчёт / печать», «Проверить воспроизводимость», «Изменить данные (новая редакция)» (прежний результат сохраняется в истории редакций), «JSON».

**Группа и динамика.** «Сводная по группе» — средние значения, место в группе, распределение по уровням (для отзывов — также ПСК и итоговая оценка), печать и CSV (по образцу табл. 8–9 диссертации). Карточка объекта — динамика (например, 4 → 5 курс), сравнение двух оценок и «Отчёт по объекту» для печати.

**Анализ отзывов.** Раздел «Анализ отзывов» формирует таблицу по форме S1 Прил. 2: по органам военного управления (поле «Округ» шапки отзыва) — сколько поступило отзывов и сколько выпускников оценено на 5/4/3/2. Основание оценки (итоговая, Псфк ВПК или bср) выбирается пользователем; число направленных выпускников вводится вручную.

**Отзыв полностью по форме S1.** Помимо оценок компетенций вводятся шапка отзыва (звание, должности, место службы, перевод/увольнение), подписи, разделы II–V и «Колонка выпускника». Для анкеты практики — оба оценщика (командир подразделения и руководитель от института).

**Групповой ввод и импорт.** «Групповой ввод» — таблица «курсанты × компетенции» на всю группу (анкеты практики или раздел I отзыва); блок оценок можно вставить из Excel (Ctrl+V), между ячейками — стрелки и Enter. Полные строки утверждаются, неполные сохраняются черновиками. «Импорт CSV» — скачайте шаблон, заполните в Excel, сохраните как CSV и загрузите: перед импортом показывается проверка каждой строки; объекты сопоставляются по ФИО и группе, отсутствующие создаются.

**Аналитика.**
- «Выпуск ↔ войска» — оценки одних и тех же компетенций на практике и в отзыве через 1 (2) года: по каждому выпускнику и по каждой компетенции (основание — S1, S4 п. 3.1).
- «Сравнение групп» — средний балл, средний Псфк, оценки руководителя и комиссии, распределение по уровням для 2–3 групп (например, КГ и ЭГ, как на рис. 12–13 гл. III).
- «Сводная по группе» → «Правило выявления расхождений» — сравнение расчётного уровня с оценкой комиссии или руководителя по правилу, которое задаёте вы (помечено «не из методики»).
- «Прогноз g по группе» — алгоритм рис. 12 для всей группы (g₀ и способности каждого обучающегося; можно вставить из Excel), график, сохранение как расчётов.
- «Чувствительность g» — графики по образцу рис. 7–10 S5.
- «Оптимизация плана» — распределение часов T1/T2 методом случайного поиска при ограничениях по семестрам (S5 ф. 25–28); результат можно сохранить новым учебным планом.

**Документы.** «Печатные бланки» — служебный отзыв (1 и 2 год) с вписанными Кзнк и анкета практики; пустые или с ФИО на всю группу (по бланку на страницу). «Отчёты о практике» — отчёт руководителя об итогах войсковой практики по пунктам S2 с автоматической таблицей результатов анкет.

**Дубли.** «Данные и резервные копии» → «Поиск дублей объектов оценки» — объединение записей одного человека (после импорта или слияния данных с разных компьютеров).

**Сохранение данных.** Данные автоматически сохраняются в хранилище браузера на этом компьютере. При открытии файла с диска некоторые браузеры и режимы (инкогнито, очистка истории, политики безопасности) могут их не сохранять. Поэтому:
- регулярно нажимайте «Данные и резервные копии» → «Сохранить резервную копию (JSON)»;
- для переноса на другой компьютер или восстановления — «Восстановить из файла…» (заменить или объединить).

**Отчёт и PDF.** В карточке расчёта — «Отчёт / печать» → «Печать / сохранить в PDF» → в системном диалоге выберите «Сохранить как PDF».

**Экспорт.** CSV исходных данных и результатов (разделитель «;», десятичная запятая — для Excel), CSV объектов, JSON утверждённых результатов.

**Настройка методики.** «Наборы Кзнк и экспертиза» — просмотр наборов источника, создание пользовательских наборов, расчёт Кзнк методом экспертных оценок (матрица рангов → W, χ², λ). «Учебные планы» и «Модели признаков» — исходные данные для g и Y. Изменение справочников не меняет ранее утверждённые расчёты; незавершённые черновики при следующем открытии пересчитываются по текущим справочникам (с уведомлением).

**Самопроверка.** Раздел «Самопроверка» запускает контрольные примеры из источников (33 проверки). В «Справочнике методики» есть вкладка «Термины»; пунктирно подчёркнутые термины и значок ⓘ показывают пояснения при наведении.

## Основные формулы

- `Псфк = Оценка × Кзнк` (по каждой компетенции), суммарный показатель — среднее арифметическое Псфк (S1);
- уровень по среднему баллу: «высокий» ≥ 4,5; «средний» ≥ 3,75; «низкий» ≥ 2,7; иначе «критический»;
- уровень по Псфк для отзыва — по таблицам методических рекомендаций (ВПК, ПСК, итог);
- g₀ = (Σx + Σy) / 5(L1 + L2); g = 1 − (1 − g₀)·exp(−p·(m·T1 + T2)/(1 − c)); Y = Σaᵢk_jᵢ / Σaᵢkᵢ.

Полные спецификации и источник каждого правила — `docs/2-паспорт-методики.md` и раздел приложения «Справочник методики».

## Ограничения

**Неподтверждённые положения (реализованы по решению пользователя, помечены в интерфейсе):**

*По решению пользователя не реализованы (в источниках нет правил):* оценка части компетенций, промежуточные показатели по видам деятельности, средний балл ОК/ПК.

*Добавлено по запросу пользователя с пометкой «не из методики»:* правило выявления расхождений между расчётом и выставленными оценками.

- граница «высокий» = 0,272 для Псфк ВПК применяется дословно, хотя по правилу построения остальных границ должна быть 0,281 — при расхождении с уровнем по bср выводится предупреждение;
- итоговая оценка ВПК + ПСК = среднее всех 21 Псфк (формула в источнике не приведена);
- формула (24) с p = 10⁻⁴ по умолчанию, (21) — режим на выбор;
- трактовка переменных формулы Y (признаки, веса, эталон) — по тексту заключения.

**Отсутствующие в материалах данные (функции не реализуются):**
- пороги уровней Псфк для 13 ВПК практики — для практики уровень определяется только по bср;
- Кзнк для ОК и ПК анкеты практики — их оценки фиксируются, но в расчёт не входят;
- методика получения Кзнк для ПСК (значения взяты из формы отзыва);
- правила числовой обработки разделов II–V отзыва и «Колонки выпускника» — только хранение и вывод;
- основание, по которому в форме «Анализ отзывов» (S1 Прил. 2) выпускник считается оценённым на 5/4/3/2, — выбирается пользователем;
- правило свёртки результатов по весам этапов 0,2 / 0,3 / 0,4 / 0,1 — приводятся справочно;
- правило автоматического выставления итоговой оценки комиссии; правило «разногласий» — только пользовательское;
- критерий «выпускник подтвердил оценку в войсках» — в сопоставлении «выпуск ↔ войска» выводятся только разности оценок;
- проверка статистической значимости различий групп;
- оптимизация плана: метод случайного поиска не гарантирует оптимум (как указано в S5); используется только формула (24);
- перечень признаков, весов и эталонов для Y, уровни для Y;
- Кзнк и ПСК для специальностей, кроме приведённых в форме отзыва (можно ввести как пользовательский набор, но пороги Псфк для него не определены).

**Технические:** проверено в Chromium (Linux); Firefox, Safari и браузеры под Windows не тестировались; сохранность данных в хранилище браузера при `file://` не гарантируется — используйте резервные копии.
