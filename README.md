# nowau
Новая программа

## Программный комплекс поддержки принятия решений по управлению резервными источниками энергоснабжения

Графическое приложение (Java 17+, Swing, без сторонних библиотек), один файл: `src/PowerBackupDss.java`.

Сборка и запуск:

```
javac -encoding UTF-8 -d out src/PowerBackupDss.java
java -cp out PowerBackupDss
```

Исполняемый jar: `jar cfe PowerBackupDss.jar PowerBackupDss -C out .`

Вкладки: нагрузки (с приоритетами) → генераторы и АКБ → параметры сети и сценарий (норма / частичное ограничение / отключение) → результаты (отчёт, графики, решения по шагам). На каждом шаге перебираются все сочетания включённых ДГУ и режимов АКБ (резерв / разряд / заряд) и выбирается вариант с минимальной стоимостью (сеть + топливо + износ + штрафы за недообеспечение − ценность запаса в АКБ).
