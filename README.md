# Регламент-ТС

Автоматизированная система учёта и контроля технических средств тыла. Один офлайн-файл `index.html`: работает без интернета и сервера, данные хранятся на этом компьютере.

* **Пункт управления** — состояние всего парка, КТГ по подразделениям, ТО, календарь работ. Каждое число открывает перечень машин, из которого можно сформировать задание.
* **Учёт** — парк техники, ТО и ремонты, путевые листы и моточасы, планирование, документы, отчёты, QR-маркировка.
* **Справочник** технических средств служб тыла с регламентами ТО и нормативной базой.
* **Сохранность данных** — резервные копии, точки восстановления, корзина, журнал изменений, проверка целостности, миграции структуры данных.
