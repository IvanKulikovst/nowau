# nowau — КРПД

**КРПД** — автономное веб-приложение (один HTML-файл) для перевода норм расхода дров из кг условного топлива в массу и объём
по приказу Росгвардии № 270 от 14.07.2025 и печати форм приложений № 1–4 к Порядку.

## Запуск

Откройте `krpd-standalone.html` в браузере (Chrome, Edge, Firefox, Safari последних версий) — двойным щелчком, по `file://`.
Сервер, установка и интернет не нужны. Данные хранятся в браузере (IndexedDB, резервная копия в localStorage);
для переноса между устройствами используйте «Файл → Экспорт данных / Импорт данных».

Встроенная самопроверка расчётного ядра: откройте файл с адресом `…/krpd-standalone.html#selftest`.

## Проверки

Требуется: Node.js 18+, Playwright с Chromium, Python 3 с `python-docx` и `openpyxl`, `poppler-utils` (`pdfinfo`, `pdftotext`).

```sh
sh tests/run-all.sh krpd-standalone.html test-output
```

| Скрипт | Что проверяет |
|---|---|
| `tests/lint.sh` | синтаксис всех встроенных скриптов (`node --check`) и ESLint |
| `tests/smoke.mjs` | запуск по `file://`, ошибки консоли, внешние запросы, встроенная самопроверка |
| `tests/calc_oracle.py` + `tests/calc_run.mjs` | 6000 случайных расчётов движка против независимой эталонной реализации (точные дроби) |
| `tests/e2e.mjs` | 66 сквозных сценариев интерфейса: лендинг, навигация, ввод и проверка полей, сохранение, импорт/экспорт, печать в PDF, выгрузка DOCX/XLSX, справочник, меню, настройки, повреждённое хранилище, адаптивность 360–1920 px, XSS |
| `tests/check_office.py` | выгруженные DOCX/XLSX открываются и содержат таблицы с итогами |
| `tests/perf.mjs` | время загрузки и отсутствие роста DOM-узлов/обработчиков после 20 циклов работы |

Если Playwright установлен глобально, укажите путь: `PW_PATH=/путь/к/node_modules/playwright sh tests/run-all.sh`.
