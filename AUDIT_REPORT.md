## B. Проверенная конфигурация

- **Тип:** автономное одностраничное веб-приложение, один HTML-файл. Ванильный JS (ES2020, BigInt), без зависимостей и сборки. Хранилище — IndexedDB с резервной копией в localStorage.
- **Среда:** Linux, Chromium 141 (Playwright 1.56, headless), открытие по `file://`, без сети.
- **Инструменты:** Playwright, ESLint 10, Python 3.13 (fractions, python-docx, openpyxl), LibreOffice (конвертация DOCX/XLSX→PDF), poppler (pdfinfo/pdftotext/pdftoppm).
- **Экраны:** 360×740, 375×812, 768×1024, 1280×800, 1440×900, 1920×1080.
- **Команды:** `sh tests/run-all.sh krpd-standalone.html test-output` (сводный запуск, см. README).
- **Финальный прогон** выполнен на итоговом состоянии файла после последнего изменения.

## F. Непроверенные области и риски

1. **Firefox, Safari, Edge, мобильные браузеры** — не запускались, в среде есть только Chromium. Риск средний: используются `color-mix`, `inert`, CSS `zoom`, `@page`-колонтитулы (Chrome 131+). Нужен ручной прогон основного сценария в каждом целевом браузере.
2. **Печать на физическом принтере** и системный диалог печати не проверялись. Печатный вид проверен через PDF Chromium.
3. **Microsoft Word / Excel** не проверялись. Файлы корректны для python-docx, openpyxl и LibreOffice; минимальный набор частей OOXML Office обычно принимает. Рекомендуется открыть по одному файлу.
4. **Значения таблиц приказа** не сверены со сканом (см. O-01).
5. **Видео лендинга (H.264)** в Chromium без проприетарных кодеков не воспроизводится, показывается постер. Это работает корректно, но само воспроизведение не проверено.

## G. Запуск и публикация

1. Итоговый артефакт: `krpd-standalone.html` в корне репозитория (ветка `claude/fervent-wozniak-skydnt`).
2. Запуск: открыть файл в браузере двойным щелчком. Сервер и интернет не нужны.
3. Проверка перед выпуском: `sh tests/run-all.sh krpd-standalone.html test-output` должен завершиться строкой «ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ».
4. Распространение: передать один файл. Данные пользователей хранятся в браузере, а не в файле. Сохранятся ли они при замене файла новой версией, зависит от того, как браузер изолирует хранилище страниц `file://`; в других браузерах это не проверялось. Перед обновлением попросите пользователей сделать «Файл → Экспорт данных».
5. Перед выпуском: сверить O-01 и вручную пройти основной сценарий в целевых браузерах (раздел F).
